# SV Sex Shop 
 
Site institucional e vitrine de produtos da SV Sex Shop. 
 
## Autora 
 
Thuane Franca 
 
## Tecnologias 
 
- React 18 
- TypeScript 
- Vite 
- Tailwind CSS 
- shadcn/ui 
- Framer Motion 
- React Router DOM 
- Lucide React 
 
## Como rodar localmente 
 
1. npm install 
2. npm run dev 
3. Acessar http://localhost:5173 
 
## Build para producao 
 
npm run build
